## How it was produced

The project was generated by `../kicad_gen/make_ecu_kicad.py` from the single design source `../kicad_gen/ecu_design.py`, which holds parts, values, nets and the Teensy pin map. Each component carries `Spec`/`Function` fields with its source tag. Run `../kicad_gen/run_all.sh` to repeat the full chain:

1. Generate the project.
2. Export the netlist with `kicad-cli`.
3. Run the cross-check.
4. Build the grouped BOM.
5. Export the PDF.
6. Run ERC.

**Warning: regenerating overwrites hand edits.** From the moment the founder edits the schematic in KiCad, KiCad is the master. After that, use `SKIP_GEN=1 ./run_all.sh` to run only the checks.

## ERC

KiCad 7.0's `kicad-cli` has no `sch erc` command; it was added in KiCad 8. The real eeschema ERC engine was therefore run through the GUI on a virtual display (Xvfb + xdotool, script `../kicad_gen/gui_erc.sh`). KiCad's own report was saved to `erc/argos_ecu_erc.rpt`, with dialog screenshots in `erc/shots/`.

**Severities.** All checks are set to error or warning in `argos_ecu.kicad_pro`, except `simulation_model_issue`, which is set to `ignore` as in KiCad's default. No SPICE models are assigned in this schematic.

**Run 1, kept as evidence.** It used the SPICE check enabled: `erc/argos_ecu_erc_run1_simcheck_enabled.rpt`, screenshot in `erc/shots_run1/`. It reported:
- 102 warnings of "no simulation model".
- 12 `endpoint_off_grid` warnings, from PWR_FLAG pairs placed at y = 266.52 mm. These were fixed by snapping to the grid.

**Negative control.** With the VBAT `PWR_FLAG` removed, ERC reports 2 errors, `power_pin_not_driven` on VBAT and `pin_not_connected` (`erc/negative_control_vbat_flag_removed.rpt`). The check is therefore live on this project.

**Independent cross-check** (`../kicad_gen/check_netlist.py`). It compares the KiCad-exported netlist pin by pin with the generator's intent. It also re-applies KiCad 7's default pin-conflict matrix and its driver rules, and checks that every footprint exists in the stock or project libraries. The result is 0 errors.

**Pins left open on purpose:**
- Pins with a no-connect flag:
  - U102 TPS54202 EN: floating means enabled (TI SLVSD26C).
  - PS501 Pololu ENABLE: 100 kΩ internal pull-up (Pololu #2895).
  - Spare buffer outputs and MAX31856 FAULT/DRDY.
- Library pins of electrical type NC need no flag: BAT54W pin 2, ADR4525 NC pins and MAX31856 DNC.

**From KiCad 8 on:** `kicad-cli sch erc --severity-all -o erc.rpt argos_ecu.kicad_sch`.

## Known limitations (open)

- No PCB layout yet. The board outline in `../ecu_outline_v2.svg` is an estimate from footprint courtyards, not a routed board.
- The `Teensy41_Socket` footprint assumes 2 x 1x24 female headers and a 61.0 x 17.8 mm outline. Check it against the PJRC drawing before ordering a board.
- `Pololu_U3V70_WireAttach` contains wire pads only. The Pololu hole pattern was not taken from a drawing, so mount the module separately.
- Footprints were chosen for hand assembly (0603 parts, TSSOP or larger). Part availability was checked only for the priced BOM lines.
- The schematic is label-connected (net-label style), which suits editing and review in KiCad. Wire routing inside each block is minimal.
